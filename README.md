# cristiandesivo-assets

Images and video for the case pages on cristiandesivo.com, served by GitHub Pages so the site itself
doesn't host or send any media files.

URL patterns:
- `https://crisdesivo.github.io/cristiandesivo-assets/img/<name>.webp` (1600×900 WebP)
- `https://crisdesivo.github.io/cristiandesivo-assets/video/<name>.mp4` (H.264, starts playing before it finishes downloading)

Sources and renders live in the private income-growth project (`reports/portfolio_*`,
`portfolio_video/`). Everything shown uses generated sample data, never client data.
